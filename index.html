FRIDGE FIRST

냉장고부터 확인하자

메뉴를 먼저 고를 필요 없어. 집에 있는 재료와 양을 입력하면 만들 수 있는 요리를 추천해 줄게.

STEP 1

현재 가지고 있는 재료

재료 이름과 대략적인 양을 입력해 줘. 한 줄에 하나씩 입력하면 비교하기 쉬워.

g, ml, 개, 큰술 등의 단위를 사용할 수 있어. 양을 모르면 재료 이름만 적어도 돼.

STEP 2 · 추가 재료 구매 가능 여부

STEP 3

추천 메뉴

0 바로 만들기
0 추가 구매 필요
0 양 확인 필요

기준은 제공된 레시피의 2인분이야. 입력한 재료의 양이 필요량보다 적으면 부족한 재료로 표시해. 단위가 다르거나 양을 모르는 경우에는 충분하다고 단정하지 않아.

STEP 4
